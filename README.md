# Extract page info with one click

一个无构建依赖的 Chrome / Edge Manifest V3 扩展原型。

## 功能

- 一键提取页面标题、简介、主题、关键段落与相关链接
- 一键复制清理后的当前页面正文
- 一键复制当前选中文本（页面侧记忆选区，避免弹窗打开后选区丢失）
- 选中文字后在页面选区附近显示浮动复制按钮，避免打开扩展弹窗导致网页失焦
- 成功复制和失败均有明确弹窗反馈，并带剪贴板回退方案
- 中文、English、日本語界面与复制结果
- 支持中文、English、日本語、한국어、Español、Français、Deutsch、Português、Русский，并可在设置中固定语言
- 快捷键：`Ctrl/⌘ + Shift + I` 提取信息，`Ctrl/⌘ + Shift + Y` 复制页面
- 本地解析，不上传页面内容

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本目录：`page-insight-extension`。

部分受保护页面（浏览器设置页、扩展商店、PDF 内置查看器等）不允许注入脚本，这是浏览器限制。
