Purpose and scope

This policy describes how Extract page info with one click handles information to extract webpage details and copy page text or selected text. The extension does not require a separate account.

Webpage content and selected text

The extension can read a page's title, URL, description, headings, paragraphs and links to produce the information you request. This processing happens in your browser. The publisher does not receive or store this content on a server.

Where browser site-access settings allow it, a bundled content script loads automatically on supported webpages. It listens for selection events and temporarily remembers selected text in the page's memory so that a floating copy button and the popup can copy your selection. This feature is active before a popup button is clicked. The extension does not keep a persistent history of selected text or extracted pages.

Clipboard

A copy button or extension keyboard shortcut writes the requested text to your system clipboard. The extension does not read existing clipboard contents. Copied text may remain in the clipboard or operating-system clipboard history according to your device settings, and other applications may access it under their own permissions. Clearing a webpage does not clear your clipboard.

Preferences and browser sync

The extension saves the language preference and the current privacy-setting value through chrome.storage.sync. Your browser provider may synchronise these preferences between devices when browser sync is enabled. Webpage text and selected text are not saved to this sync storage. The publisher does not operate the browser's sync service.

In version 1.3.0, the privacy-setting checkbox saves a preference only; changing it does not enable any server-side processing. Page content is processed locally in either setting.

Sharing and limited use

The extension does not send webpage content, selected text or browsing history to the publisher, analytics services, advertising services or external AI services. It does not sell this information or use it for advertising, creditworthiness or lending decisions. Data is used only for the page-extraction and copying features described here, consistent with the Chrome Web Store User Data Policy and its Limited Use requirements.

All executable extension code is included in the installation package. The extension does not download and execute remote code.

Retention and controls

The remembered selection is held in page memory until replaced or the page context is destroyed, such as when the page is reloaded or closed. Preferences remain in browser storage until changed or cleared through the browser's extension-data and sync controls. You can change language in Settings, restrict site access or disable/uninstall the extension through your browser, and separately clear your device's clipboard history. The publisher has no server-side copy of extracted content to delete.

This website and contact

The published policy page is hosted using GitHub Pages. Requests to this page are handled by GitHub under its own privacy practices; this page contains no added analytics scripts or tracking cookies.

For privacy questions, use the public contact information or project links on the maintainer's GitHub profile. Avoid posting sensitive webpage content in public issues. This policy will be updated when the extension's data handling changes.

用途与范围

本政策说明 Extract page info with one click 在提取网页信息、复制网页文字和选中文字时如何处理数据。使用扩展无需另行注册账号。

网页内容与选中文字

扩展根据你的操作读取当前网页的标题、网址、简介、各级标题、段落和链接，处理过程在浏览器中进行。发布者不会在服务器上接收或保存这些内容。

在浏览器允许访问的网站上，扩展内置的页面脚本会自动加载，监听选区变化，并将选中文字暂存在当前页面内存中，以便显示浮动复制按钮和通过弹窗复制。这项功能在点击弹窗按钮之前就会运行。扩展不持久保存选中文字或提取记录。

剪贴板

点击复制按钮或触发扩展快捷键后，扩展将相应文字写入系统剪贴板，不读取原有剪贴板内容。复制的文字可能按照系统设置保留在剪贴板或剪贴板历史记录中；其他应用能否访问取决于其权限。关闭网页不会清空剪贴板。

偏好设置与浏览器同步

语言偏好和当前隐私设置值保存在 chrome.storage.sync 中。启用浏览器同步后，浏览器提供商可能会在设备之间同步这些偏好设置；网页正文和选中文字不会写入该同步存储。发布者不运营此同步服务。

1.3.0 版本的“隐私模式”复选框仅保存偏好值，切换它不会开启服务器处理。无论该选项如何设置，页面内容均在本地处理。

共享与有限用途

扩展不会将网页内容、选中文字或浏览历史发送给发布者、分析服务、广告服务或外部 AI 服务，不出售这些信息，不将其用于广告、信用评估或贷款决策。数据仅用于本政策描述的提取和复制功能，遵循 Chrome Web Store 用户数据政策及其有限用途要求。所有可执行代码均随安装包提供，不下载并执行远程代码。

保留与控制

记忆的选中文字在被替换或页面上下文销毁（例如刷新或关闭页面）后不再保留。偏好设置持续保存在浏览器存储中，直到通过设置或浏览器的扩展数据、同步管理功能修改或清除。你可以切换语言、限制网站访问、停用或卸载扩展，并单独管理系统剪贴板历史。发布者没有可供删除的网页内容服务器副本。

本网页与联系

发布后的政策网页由 GitHub Pages 托管，访问请求由 GitHub 按其隐私规则处理；本网页没有额外添加统计脚本或追踪 Cookie。如有隐私问题，可通过维护者的 GitHub 主页上公开的联系方式或项目入口联系，请勿在公开问题中提交敏感网页内容。数据处理方式变化时会更新本政策。
