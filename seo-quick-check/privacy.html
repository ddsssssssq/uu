Purpose and scope

SEO Quick Check is a browser extension that provides a local, on-page SEO health report for the webpage that you choose to analyze. This policy explains what the extension reads and how it handles that information.

Local webpage analysis

After you invoke the extension, it reads the current page URL and top-level DOM to inspect titles, meta descriptions, canonical links, robots metadata, headings, images, links, Open Graph and Twitter metadata, hreflang, JSON-LD structured data, basic technical metadata, and visible text statistics. The analysis happens locally in your browser.

The extension does not upload URLs, HTML, page text, extracted metadata, browsing history, or SEO reports to the publisher, analytics providers, advertising networks, AI services, or other external servers. It does not crawl websites, request external links, download images, or run a background monitor.

Permissions

activeTab gives the extension temporary access to the page you actively choose by invoking the extension. scripting lets it run the analyzer bundled inside the extension on that page. The extension does not request permanent access to all websites, browsing history, cookies, bookmarks, downloads, or web requests.

Clipboard

When you click Copy, the extension writes the report or a selected field to your system clipboard. It does not read existing clipboard contents. Clipboard retention and history are controlled by your operating system.

Language preference

The interface follows your browser's preferred language by default and supports English and Simplified Chinese. If you manually choose a language, that preference is stored locally in the extension popup's browser storage. Selecting Browser default removes the manual override. This preference does not contain page content and is never transmitted.

Storage and retention

SEO reports are held in popup memory and are discarded when the popup closes. The extension does not maintain a database, account, cloud report, or browsing history. The language preference remains until you change it or clear the extension's local data.

Remote code and tracking

All executable JavaScript and CSS is included in the extension package. The extension does not load or execute remote code, use analytics, set tracking cookies, or include third-party tracking scripts.

Hosting and contact

This privacy policy is hosted on GitHub Pages. Requests to this page are handled by GitHub under GitHub's own privacy practices. This page does not add analytics scripts or tracking cookies.

For questions about SEO Quick Check, use the public contact information on the maintainer's GitHub profile. Do not post sensitive webpage content in public issues.

用途与范围

SEO Quick Check 是一个浏览器扩展，用于在本地分析用户主动选择的当前网页，并生成页面 SEO 健康报告。本政策说明扩展读取哪些信息以及如何处理这些信息。

本地网页分析

用户启动扩展后，扩展读取当前网页 URL 和顶层 DOM，用于检查标题、描述、规范网址、robots 元数据、标题结构、图片、链接、Open Graph 和 Twitter 元数据、hreflang、JSON-LD 结构化数据、基础技术信息以及可见文本统计。分析过程完全在浏览器本地完成。

扩展不会将 URL、HTML、网页文本、提取的元数据、浏览历史或 SEO 报告上传给发布者、分析服务、广告网络、AI 服务或其他外部服务器。扩展不会爬取网站、请求外部链接、下载图片或在后台监控页面。

权限

activeTab 用于在用户主动启动扩展后，临时访问用户选择的当前网页。scripting 用于在该页面执行扩展安装包内置的分析器。扩展不申请永久访问所有网站、浏览历史、Cookie、书签、下载或网络请求权限。

剪贴板

用户点击复制按钮后，扩展会将报告或选定字段写入系统剪贴板。扩展不会读取已有的剪贴板内容。剪贴板的保存和历史记录由操作系统控制。

语言偏好

界面默认跟随浏览器首选语言，支持 English 和简体中文。如果用户手动选择语言，该偏好会保存在扩展弹窗的本地浏览器存储中。选择“跟随浏览器”会清除手动设置。语言偏好不包含网页内容，也不会被传输。

存储与保留

SEO 报告仅保存在弹窗内存中，弹窗关闭后即丢弃。扩展不维护数据库、用户账号、云端报告或浏览历史。语言偏好会一直保留，直到用户修改或清除扩展本地数据。

远程代码与追踪

所有可执行 JavaScript 和 CSS 都包含在扩展安装包内。扩展不加载或执行远程代码，不使用分析服务，不设置追踪 Cookie，也不包含第三方追踪脚本。

托管与联系

本隐私政策由 GitHub Pages 托管。访问本页面的请求由 GitHub 按其自身隐私规则处理。本页面不添加分析脚本或追踪 Cookie。

如需联系 SEO Quick Check，请通过维护者的 GitHub 主页上的公开信息联系。请勿在公开问题中提交敏感网页内容。
